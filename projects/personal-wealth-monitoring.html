Personal Wealth Monitoring System

A personal-finance application focused on bringing investment holdings, transaction history, mutual funds, SIPs, and portfolio analysis into one place.

PythonDjango REST FrameworkAngularSQLMarket data integration

The problem

Investment information can be spread across transaction exports, market-price sources, mutual-fund NAV data, and separate asset categories. Comparing positions consistently requires a clear data model and repeatable calculations.

The approach

Use a Django API to manage application data and calculation logic, with an Angular frontend for portfolio views, investment workflows, and analytics.

Product areas

  • Portfolio and holdings: organize investments and current positions.
  • Transactions: preserve the underlying activity used to derive holdings and performance.
  • Mutual funds and SIPs: track units, NAV-based values, and recurring investment records.
  • Analytics: compare costs and current values while separating realized and unrealized performance where the data supports it.
  • Market data: integrate external price/NAV sources with clear handling for missing or stale values.

Important engineering decisions

Financial calculations need explicit conventions: transaction ordering, units and currency precision, treatment of fees, split/bonus events where relevant, stale-price indicators, and reconciliation between transaction-derived holdings and imported closing balances. A useful dashboard should make assumptions visible rather than hide them behind a single total.

What this demonstrates

  • Building a full-stack application with a separate API and frontend.
  • Integrating market-data inputs with user-managed investment records.
  • Designing reporting around transaction-level data and calculation consistency.

This page describes application scope and design; it does not claim audited financial accuracy or investment performance.
